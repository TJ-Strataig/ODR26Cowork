# Onder de Radar zaterdagplanner - GitHub Pages

`index.html` bevat de volledige app. `.nojekyll` zorgt ervoor dat GitHub Pages de site eenvoudig kan publiceren.

## Publiceren

1. Maak een nieuw GitHub-repository.
2. Upload de drie bestanden uit dit pakket.
3. Commit de bestanden.
4. Ga naar **Settings > Pages**.
5. Kies **Deploy from a branch**.
6. Selecteer branch **main** en map **/(root)**.
7. Klik op **Save**.
8. Wacht tot de Pages-URL verschijnt.

## Op iPhone

1. Open de Pages-URL in Safari.
2. Tik op **Deel**.
3. Kies **Zet op beginscherm**.

Voorkeuren worden lokaal op dat webadres opgeslagen.

**Let op:** verwijder of hernoem `index.html` niet. Gebruik steeds dezelfde Pages-URL om voorkeuren te behouden.
